▶ Connection & Setup -- how to use this tool with or without the DRAGEN server
Without DRAGEN (default)
Open this file in any browser. All panel variants load from embedded data. Frequency lookups use public APIs: gnomAD v4, ClinVar, and 1000 Genomes. No setup required.
Works offline for embedded data
With DRAGEN (live UZB data)
Connects to the DRAGEN server to query UZB allele frequencies for any variant -- not just the built-in panel. Requires the frequency server running on DRAGEN and an SSH tunnel or Tailscale connection.
Start the frequency server on DRAGEN:
nohup python3 /staging/ALSU-analysis/admixture_analysis/uzb_freq/uzb_freq_server.py > uzb_server.log 2>&1 &
Open SSH tunnel from your PC:
plink.exe -batch -i id_ed25519.ppk -N -L 8765:localhost:8765 copilot@100.104.25.22
From another PC (Tailscale)
Any PC on the same Tailscale network can reach the server directly without a tunnel. Change the server bind address once and set the URL below.
One-time server change:
sed -i "s/127.0.0.1/0.0.0.0/" uzb_freq_server.py
Set server address:
Local tunnel: http://127.0.0.1:8765
Tailscale direct: http://100.104.25.22:8765
